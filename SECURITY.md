## Security Policy

We strongly recommend using the latest version of Tracelight to receive all security updates.

Tracelight is a modified fork of Langfuse. If you find a vulnerability in Tracelight, please do not open a public issue. Contact the maintainer privately at adil.mern.ai@gmail.com with a description and steps to reproduce.

Vulnerabilities in the original Langfuse project should be reported to that project.
